# 数据分析专家示例 - 完整模拟数据

## 概述

本示例展示了EFIAgent 2.0架构中一个完整的销售数据分析场景，演示了能力模块、Agent模块和工作流模块三层架构的协同工作。该示例模拟了从数据摄取到报告生成的完整数据分析流程。

## 架构组成

### 1. 能力模块层 (7个能力模块)

- **数据摄取能力** (`cap_data_ingestion_001`)
  - 支持多种数据源（数据库、文件、API）
  - 自动数据格式检测和转换
  - 连接池管理和错误重试

- **数据清洗能力** (`cap_data_cleaning_002`)
  - 缺失值处理和异常值检测
  - 数据类型转换和格式标准化
  - 数据质量评分和报告

- **统计分析能力** (`cap_statistical_analysis_003`)
  - 描述性统计分析
  - 假设检验和相关性分析
  - 分布分析和置信区间计算

- **趋势分析能力** (`cap_trend_analysis_004`)
  - 时间序列趋势识别
  - 季节性模式检测
  - 变点分析和异常检测

- **预测建模能力** (`cap_prediction_model_005`)
  - 多种机器学习算法支持
  - 自动特征工程和模型选择
  - 交叉验证和超参数调优

- **数据可视化能力** (`cap_visualization_006`)
  - 多种图表类型支持
  - 交互式可视化
  - 自定义主题和样式

- **报告生成能力** (`cap_report_generation_007`)
  - 多格式报告输出
  - 模板化报告生成
  - 多语言支持

### 2. Agent模块层 (4个专家Agent)

- **数据处理专家Agent** (`agent_data_processor_001`)
  - 组合数据摄取和清洗能力
  - 数据质量监控和验证
  - 自动化数据预处理流程

- **数据分析专家Agent** (`agent_data_analyst_002`)
  - 组合统计分析和趋势分析能力
  - 智能分析策略选择
  - 分析结果解释和洞察提取

- **预测建模专家Agent** (`agent_predictor_003`)
  - 专注于预测建模任务
  - 模型性能优化
  - 预测结果验证和评估

- **报告生成专家Agent** (`agent_reporter_004`)
  - 组合可视化和报告生成能力
  - 智能报告结构设计
  - 多渠道报告分发

### 3. 工作流模块层 (1个完整工作流)

- **销售数据分析工作流** (`workflow_sales_analysis_001`)
  - 协调4个专家Agent的执行
  - 支持多种触发方式（定时、事件、手动、API）
  - 完整的错误处理和监控机制

## 工作流执行流程

```
开始 → 数据处理 → 数据清洗 → 数据分析 → 预测建模 → 数据可视化 → 报告生成 → 结束
         ↓           ↓           ↓           ↓
      错误处理 ← 错误处理 ← 错误处理 ← 错误处理
```

### 执行步骤详解

1. **数据处理阶段**
   - 连接数据源，摄取原始销售数据
   - 数据格式验证和初步清洗
   - 数据质量评估

2. **数据清洗阶段**
   - 处理缺失值和异常值
   - 数据标准化和格式统一
   - 质量阈值检查（≥85%）

3. **数据分析阶段**
   - 并行执行统计分析和趋势分析
   - 生成描述性统计报告
   - 识别销售趋势和模式

4. **预测建模阶段**
   - 构建集成预测模型
   - 模型训练和验证
   - 生成未来6个月销售预测

5. **可视化阶段**
   - 生成多种类型图表
   - 创建交互式仪表板
   - 可视化分析结果

6. **报告生成阶段**
   - 整合所有分析结果
   - 生成PDF格式执行摘要
   - 多语言报告支持

## 触发机制

### 1. 定时触发
- **频率**: 每月1号自动执行
- **时区**: Asia/Shanghai
- **并发控制**: 最多1个实例同时运行

### 2. 事件触发
- **事件类型**: 新销售数据到达
- **防抖时间**: 5分钟
- **最小记录数**: 100条

### 3. 手动触发
- **权限**: 数据分析师、经理
- **审批**: 无需审批

### 4. API触发

- **认证**: Bearer Token
