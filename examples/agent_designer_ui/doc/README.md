# EFIAgent 可视化Agent开发模块

## 概述

可视化Agent开发模块是EFIAgent系统的重要组成部分，旨在通过图形化界面简化Agent的设计、配置和部署流程。该模块允许用户通过拖拽组件、配置参数和可视化工作流的方式，快速创建和管理自定义智能体，无需编写复杂的代码。

## 主要功能

- **可视化Agent设计器**：通过拖拽组件方式设计Agent功能和行为
- **模板库**：提供各类型Agent的预设模板
- **能力市场**：提供可复用的Agent能力组件
- **可视化工作流编排**：设计Agent之间的协作流程
- **实时调试与测试**：在线测试Agent行为和性能
- **一键部署**：将设计好的Agent快速部署到生产环境

## 技术栈

- **前端**：React, TypeScript, Ant Design
- **后端**：FastAPI, Python 3.9+
- **数据存储**：PostgreSQL, Redis

## 安装指南

### 前端安装

1. 确保已安装Node.js (v14+)和npm (v6+)

2. 安装依赖

```bash
cd examples/agent_designer_ui
npm install
```

3. 启动开发服务器

```bash
npm start
```

### 后端安装

1. 确保已安装Python 3.9+

2. 创建虚拟环境

```bash
python -m venv venv
source venv/bin/activate  # Linux/Mac
venv\Scripts\activate  # Windows
```

3. 安装依赖

```bash
cd examples/agent_designer_api
pip install -r requirements.txt
```

4. 启动API服务

```bash
python app.py
```

## 使用指南

### 创建新Agent

1. 打开Agent设计器页面
2. 从左侧组件面板拖拽组件到中央画布
3. 在右侧属性面板配置组件参数
4. 点击保存按钮保存Agent配置

### 使用模板

1. 打开模板库页面
2. 浏览可用的Agent模板
3. 点击"使用"按钮选择模板
4. 根据需要调整模板参数
5. 保存为新的Agent实例

### 设计工作流

1. 打开工作流设计页面
2. 添加Agent节点
3. 连接节点定义工作流
4. 配置节点间的条件和依赖
5. 保存工作流配置

### 调试与测试

1. 在Agent设计器中选择要测试的Agent
2. 切换到调试面板
3. 点击运行按钮启动Agent
4. 查看日志输出和状态信息

## 示例

### 创建规划智能体

1. 从模板库选择"规划智能体模板"
2. 添加"任务分析"和"子任务生成"能力
3. 配置规划策略为"分层规划"
4. 设置模型参数和资源需求
5. 保存并部署

4. 设置超时和重试参数
5. 保存并部署

## 常见问题

**Q: 如何在已有Agent中添加新能力？**

A: 打开Agent设计器，选择目标Agent，从能力市场拖拽新能力到画布，配置参数后保存。

**Q: 如何调试Agent运行错误？**

A: 在调试面板中查看日志输出，定位错误原因，修改配置或能力参数后重新运行。

**Q: 如何在不同环境中部署Agent？**

A: 在部署页面选择目标环境（本地、云端或边缘），配置部署参数，点击部署按钮。
