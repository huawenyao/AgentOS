## 1. 系统概述

EFIAgent是一个企业级多智能体协作系统，采用分层联邦架构设计，实现了高效的任务规划、执行和审核流程。系统由规划智能体、执行智能体组、审核智能体组和记忆智能体组成，通过动态角色引擎、混合通信拓扑和三阶段进化协议实现高效协作。

系统主要特点：

- **分层联邦架构**：采用分层设计，实现任务的高效分解和执行
- **基于LLM的任务规划**：利用大语言模型进行任务分析和规划
- **动态资源调度**：根据任务需求和资源状态动态分配资源
- **技能向量匹配**：根据智能体技能和任务需求进行精准匹配
- **自适应执行策略**：根据执行情况动态调整执行策略
- **故障容错**：具备故障检测和恢复机制

## 2. 安装与配置

### 2.1 环境要求

- Python 3.9+
- 操作系统：Windows/Linux/MacOS
- 内存：至少8GB
- 存储：至少10GB可用空间
- 可选：NVIDIA GPU（用于加速LLM推理）

### 2.2 安装步骤

#### 从PyPI安装

```bash
pip install efiagent
```

#### 从源码安装

```bash
# 克隆代码库
git clone https://github.com/wumaitech/EFIAgent.git
cd EFIAgent

# 安装依赖
pip install -r requirements.txt

# 安装开发模式
pip install -e .
```

### 2.3 配置说明

系统配置文件默认位于`~/.efiagent/config.json`，您可以通过`--config`参数指定自定义配置文件路径。

主要配置项包括：

- **system**：系统全局配置
  - `debug`：是否开启调试模式
  - `log_level`：日志级别
  - `api_port`：API服务端口
  - `max_workers`：最大工作线程数

- **agents**：智能体配置
  - `planning`：规划智能体配置
  - `execution`：执行智能体配置
  - `review`：审核智能体配置
  - `memory`：记忆智能体配置

- **resources**：资源配置
  - `cpu_limit`：CPU使用限制
  - `memory_limit`：内存使用限制
  - `gpu_limit`：GPU使用限制

- **storage**：存储配置
  - `type`：存储类型（local, s3, etc.）
  - `path`：本地存储路径
  - `credentials`：云存储凭证

## 3. 系统启动与停止

### 3.1 启动系统

使用命令行工具启动系统：

```bash
# 使用默认配置启动
efiagent start

# 使用自定义配置文件启动
efiagent start --config /path/to/config.json

# 开启调试模式启动
efiagent start --debug
```

系统启动后，将初始化资源调度器、规划智能体、执行智能体池、审核智能体，并启动API服务。

### 3.2 停止系统

在终端中按`Ctrl+C`可以优雅地停止系统，系统会保存当前状态并关闭所有组件。

## 4. 智能体管理

### 4.1 创建智能体

使用命令行工具创建新的智能体：

```bash
# 创建规划智能体
efiagent create-agent --type planning --name "主规划智能体"

# 创建执行智能体
efiagent create-agent --type execution --name "执行智能体1"

# 创建审核智能体
efiagent create-agent --type reviewer --name "审核智能体1"
```

### 4.2 查看智能体列表

使用命令行工具查看当前系统中的所有智能体：

```bash
efiagent list-agents
```

输出示例：

## 5. 任务管理

### 5.1 创建任务

任务以JSON格式定义，包含任务名称、描述、优先级、截止日期、请求者、参数、约束条件等信息。

任务文件示例（`task_example.json`）：

```json
{
    "name": "数据分析任务",
    "description": "分析销售数据并生成报告",
    "priority": "high",
    "deadline": "2023-12-31T23:59:59",
    "requester": "user-001",
    "parameters": {
        "data_source": "sales_data_2023.csv",
        "output_format": "pdf",
        "analysis_type": "trend",
        "time_range": {
            "start": "2023-01-01",
            "end": "2023-11-30"
        }
    },
    "constraints": {
        "max_execution_time": 3600,
        "max_resource_usage": {
            "cpu_cores": 4,
            "memory_mb": 8192,
            "gpu_cores": 0
        }
    },
    "callbacks": {
        "on_complete": "http://example.com/api/callback/complete",
        "on_error": "http://example.com/api/callback/error"
    }
}
```

### 5.2 提交任务

使用命令行工具提交任务：

```bash
efiagent submit-task --file path/to/task_example.json
```

提交成功后，系统将返回任务ID，可用于后续监控任务进度。

### 5.3 监控任务

使用命令行工具监控任务进度：

```bash
efiagent monitor-task --id task-20231101100000
```

## 6. 常用脚本

### 6.1 命令行工具

EFIAgent提供了命令行工具`efiagent`，用于管理系统、智能体和任务。以下是常用命令：

```bash
# 显示帮助信息
efiagent --help

# 启动系统
efiagent start [--config CONFIG_PATH] [--debug]

# 创建智能体
efiagent create-agent --type TYPE --name NAME [--config CONFIG_PATH]

# 列出智能体
efiagent list-agents [--config CONFIG_PATH]

# 提交任务
efiagent submit-task --file TASK_FILE [--config CONFIG_PATH]

# 监控任务
efiagent monitor-task --id TASK_ID [--config CONFIG_PATH]
```

### 6.2 示例脚本

#### 批量提交任务脚本

```python
#!/usr/bin/env python
# -*- coding: utf-8 -*-
"""
批量提交任务脚本

该脚本用于批量提交任务文件夹中的所有任务。
"""

import os
import sys
import argparse
import subprocess
from glob import glob

def main():
    parser = argparse.ArgumentParser(description="批量提交任务")
    parser.add_argument("--dir", "-d", required=True, help="任务文件夹路径")
    parser.add_argument("--config", "-c", help="配置文件路径")
    args = parser.parse_args()
    
    # 检查文件夹是否存在
    if not os.path.isdir(args.dir):
        print(f"错误: 文件夹不存在 {args.dir}")
        sys.exit(1)
    
    # 获取所有JSON文件
    task_files = glob(os.path.join(args.dir, "*.json"))
    if not task_files:
        print(f"错误: 文件夹中没有JSON任务文件 {args.dir}")
        sys.exit(1)
    
    # 批量提交任务
    success_count = 0
    for task_file in task_files:
        cmd = ["efiagent", "submit-task", "--file", task_file]
        if args.config:
            cmd.extend(["--config", args.config])
        
        try:
            result = subprocess.run(cmd, check=True, capture_output=True, text=True)
            print(f"成功提交任务: {os.path.basename(task_file)}")
            print(result.stdout)
            success_count += 1
        except subprocess.CalledProcessError as e:
            print(f"提交任务失败: {os.path.basename(task_file)}")
            print(e.stderr)
    
    print(f"\n总结: 成功提交 {success_count}/{len(task_files)} 个任务")

if __name__ == "__main__":
    main()
```

## 7. 故障排除

### 7.1 常见问题

#### 系统启动失败

**问题**：系统启动时报错

**解决方案**：
1. 检查配置文件是否正确
2. 检查依赖项是否安装完整
3. 检查日志文件中的详细错误信息
4. 尝试使用`--debug`模式启动，获取更多调试信息

#### 任务执行失败

**问题**：任务提交后执行失败

**解决方案**：
1. 检查任务定义是否符合格式要求
2. 检查任务参数是否正确
3. 查看日志文件中的错误信息
4. 检查资源是否足够（CPU、内存、GPU等）

#### 智能体连接问题

**问题**：智能体无法连接或通信失败

**解决方案**：
1. 检查网络连接是否正常
2. 检查智能体配置是否正确
3. 重启问题智能体
4. 检查系统防火墙设置

### 7.2 日志分析

系统日志默认保存在`logs/`目录下，按日期命名，如`efiagent_2023-11-01.log`。

日志级别可以在配置文件中设置，支持的级别有：
- DEBUG：详细的调试信息
- INFO：一般信息
- WARNING：警告信息
- ERROR：错误信息
- CRITICAL：严重错误信息

常用日志分析命令：

```bash
# 查看最新的日志
tail -f logs/efiagent_$(date +%Y-%m-%d).log

# 查找错误信息
grep ERROR logs/efiagent_*.log

# 查找特定任务的日志
grep "task-20231101100000" logs/efiagent_*.log
```

### 8.2 API参考

EFIAgent提供了RESTful API，可用于与系统进行交互。API服务默认在`http://localhost:8000`上运行。

#### 主要API端点

- **GET /api/v1/agents**：获取所有智能体列表
- **POST /api/v1/agents**：创建新智能体
- **GET /api/v1/agents/{agent_id}**：获取特定智能体信息
- **PUT /api/v1/agents/{agent_id}**：更新智能体配置
- **DELETE /api/v1/agents/{agent_id}**：删除智能体

- **GET /api/v1/tasks**：获取所有任务列表
- **POST /api/v1/tasks**：提交新任务
- **GET /api/v1/tasks/{task_id}**：获取特定任务信息
- **DELETE /api/v1/tasks/{task_id}**：取消任务

- **GET /api/v1/system/status**：获取系统状态
- **GET /api/v1/system/resources**：获取资源使用情况

详细的API文档可通过访问`http://localhost:8000/docs`获取。
