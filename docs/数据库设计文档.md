# EFIAgent 数据库设计文档

## 概述

本文档描述了EFIAgent可视化开发平台的数据库设计，包括所有核心实体的表结构、关系和索引设计。

## 数据库配置

- **数据库类型**: MySQL 8.0+
- **字符集**: utf8mb4
- **排序规则**: utf8mb4_unicode_ci
- **存储引擎**: InnoDB

## 核心表设计

### 1. 用户管理

#### users - 用户表
```sql
CREATE TABLE users (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    username VARCHAR(50) NOT NULL UNIQUE COMMENT '用户名',
    email VARCHAR(100) NOT NULL UNIQUE COMMENT '邮箱',
    password_hash VARCHAR(255) NOT NULL COMMENT '密码哈希',
    role ENUM('admin', 'developer', 'user') DEFAULT 'user' COMMENT '用户角色',
    avatar_url VARCHAR(500) COMMENT '头像URL',
    is_active BOOLEAN DEFAULT TRUE COMMENT '是否激活',
    last_login_at TIMESTAMP NULL COMMENT '最后登录时间',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    INDEX idx_username (username),
    INDEX idx_email (email),
    INDEX idx_role (role),
    INDEX idx_created_at (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='用户表';
```

### 2. Agent管理

#### agent_templates - Agent模板表
```sql
CREATE TABLE agent_templates (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL COMMENT '模板名称',
    description TEXT COMMENT '模板描述',
    type ENUM('planning', 'execution', 'audit', 'memory') NOT NULL COMMENT 'Agent类型',
    category VARCHAR(50) COMMENT '分类',
    icon_url VARCHAR(500) COMMENT '图标URL',
    difficulty ENUM('beginner', 'intermediate', 'advanced') DEFAULT 'beginner' COMMENT '难度等级',
    featured BOOLEAN DEFAULT FALSE COMMENT '是否推荐',
    properties JSON COMMENT '属性定义',
    components JSON COMMENT '组件配置',
    capabilities JSON COMMENT '能力配置',
    tags JSON COMMENT '标签',
    author_id BIGINT COMMENT '作者ID',
    version VARCHAR(20) DEFAULT '1.0.0' COMMENT '版本号',
    download_count INT DEFAULT 0 COMMENT '下载次数',
    rating DECIMAL(3,2) DEFAULT 0.00 COMMENT '评分',
    is_public BOOLEAN DEFAULT TRUE COMMENT '是否公开',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    FOREIGN KEY (author_id) REFERENCES users(id) ON DELETE SET NULL,
    INDEX idx_type (type),
    INDEX idx_category (category),
    INDEX idx_author (author_id),
    INDEX idx_featured (featured),
    INDEX idx_public (is_public),
    INDEX idx_created_at (created_at),
    FULLTEXT idx_search (name, description)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='Agent模板表';
```

#### agent_configs - Agent配置表
```sql
CREATE TABLE agent_configs (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    template_id BIGINT NOT NULL COMMENT '模板ID',
    name VARCHAR(100) NOT NULL COMMENT 'Agent名称',
    description TEXT COMMENT 'Agent描述',
    type ENUM('planning', 'execution', 'audit', 'memory') NOT NULL COMMENT 'Agent类型',
    status ENUM('idle', 'running', 'stopped', 'paused', 'error', 'completed') DEFAULT 'idle' COMMENT '状态',
    properties JSON COMMENT '属性配置',
    components JSON COMMENT '组件配置',
    capabilities JSON COMMENT '能力配置',
    owner_id BIGINT NOT NULL COMMENT '所有者ID',
    last_run_at TIMESTAMP NULL COMMENT '最后运行时间',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    FOREIGN KEY (template_id) REFERENCES agent_templates(id) ON DELETE CASCADE,
    FOREIGN KEY (owner_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_template (template_id),
    INDEX idx_owner (owner_id),
    INDEX idx_type (type),
    INDEX idx_status (status),
    INDEX idx_created_at (created_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='Agent配置表';
```

### 3. 工作流管理

#### workflows - 工作流表
```sql
CREATE TABLE workflows (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    name VARCHAR(100) NOT NULL COMMENT '工作流名称',
    description TEXT COMMENT '工作流描述',
    status ENUM('draft', 'active', 'paused', 'stopped', 'error') DEFAULT 'draft' COMMENT '状态',
    nodes JSON COMMENT '节点配置',
    connections JSON COMMENT '连接配置',
    agents JSON COMMENT 'Agent配置',
    properties JSON COMMENT '属性配置',
    tags JSON COMMENT '标签',
    author_id BIGINT NOT NULL COMMENT '作者ID',
    version VARCHAR(20) DEFAULT '1.0.0' COMMENT '版本号',
    execution_count INT DEFAULT 0 COMMENT '执行次数',
    success_count INT DEFAULT 0 COMMENT '成功次数',
    success_rate DECIMAL(5,2) DEFAULT 0.00 COMMENT '成功率',
    last_executed_at TIMESTAMP NULL COMMENT '最后执行时间',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    FOREIGN KEY (author_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_author (author_id),
    INDEX idx_status (status),
    INDEX idx_created_at (created_at),
    FULLTEXT idx_search (name, description)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='工作流表';
```

#### workflow_executions - 工作流执行记录表
```sql
CREATE TABLE workflow_executions (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    workflow_id BIGINT NOT NULL COMMENT '工作流ID',
    status ENUM('running', 'completed', 'failed', 'cancelled') DEFAULT 'running' COMMENT '执行状态',
    started_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '开始时间',
    completed_at TIMESTAMP NULL COMMENT '完成时间',
    duration INT COMMENT '执行时长(秒)',
    input_data JSON COMMENT '输入数据',
    output_data JSON COMMENT '输出数据',
    error_message TEXT COMMENT '错误信息',
    execution_log JSON COMMENT '执行日志',
    triggered_by BIGINT COMMENT '触发用户ID',
    
    FOREIGN KEY (workflow_id) REFERENCES workflows(id) ON DELETE CASCADE,
    FOREIGN KEY (triggered_by) REFERENCES users(id) ON DELETE SET NULL,
    INDEX idx_workflow (workflow_id),
    INDEX idx_status (status),
    INDEX idx_started_at (started_at),
    INDEX idx_triggered_by (triggered_by)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='工作流执行记录表';
```

### 6. 监控和日志

#### agent_instances - Agent实例表
```sql
CREATE TABLE agent_instances (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    config_id BIGINT NOT NULL COMMENT '配置ID',
    name VARCHAR(100) NOT NULL COMMENT '实例名称',
    status ENUM('idle', 'running', 'stopped', 'paused', 'error', 'completed') DEFAULT 'idle' COMMENT '状态',
    process_id VARCHAR(50) COMMENT '进程ID',
    host_info JSON COMMENT '主机信息',
    started_at TIMESTAMP NULL COMMENT '启动时间',
    stopped_at TIMESTAMP NULL COMMENT '停止时间',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '创建时间',
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP COMMENT '更新时间',
    
    FOREIGN KEY (config_id) REFERENCES agent_configs(id) ON DELETE CASCADE,
    INDEX idx_config (config_id),
    INDEX idx_status (status),
    INDEX idx_started_at (started_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='Agent实例表';
```

#### performance_metrics - 性能指标表
```sql
CREATE TABLE performance_metrics (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    agent_id BIGINT NOT NULL COMMENT 'Agent实例ID',
    metric_type ENUM('response_time', 'throughput', 'success_rate', 'error_rate', 'cpu_usage', 'memory_usage', 'token_usage') NOT NULL COMMENT '指标类型',
    value DECIMAL(10,4) NOT NULL COMMENT '指标值',
    unit VARCHAR(20) COMMENT '单位',
    timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '时间戳',
    metadata JSON COMMENT '元数据',
    
    FOREIGN KEY (agent_id) REFERENCES agent_instances(id) ON DELETE CASCADE,
    INDEX idx_agent (agent_id),
    INDEX idx_type (metric_type),
    INDEX idx_timestamp (timestamp),
    INDEX idx_agent_type_time (agent_id, metric_type, timestamp)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='性能指标表';
```

#### system_logs - 系统日志表
```sql
CREATE TABLE system_logs (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    agent_id BIGINT COMMENT 'Agent实例ID',
    level ENUM('debug', 'info', 'warn', 'error') NOT NULL COMMENT '日志级别',
    message TEXT NOT NULL COMMENT '日志消息',
    module VARCHAR(100) COMMENT '模块名称',
    function_name VARCHAR(100) COMMENT '函数名称',
    line_number INT COMMENT '行号',
    stack_trace TEXT COMMENT '堆栈跟踪',
    metadata JSON COMMENT '元数据',
    timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '时间戳',
    
    FOREIGN KEY (agent_id) REFERENCES agent_instances(id) ON DELETE CASCADE,
    INDEX idx_agent (agent_id),
    INDEX idx_level (level),
    INDEX idx_timestamp (timestamp),
    INDEX idx_module (module),
    FULLTEXT idx_message (message)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='系统日志表';
```

#### messages - 消息表
```sql
CREATE TABLE messages (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    agent_id BIGINT NOT NULL COMMENT 'Agent实例ID',
    direction ENUM('incoming', 'outgoing') NOT NULL COMMENT '消息方向',
    content TEXT NOT NULL COMMENT '消息内容',
    content_type VARCHAR(50) DEFAULT 'text' COMMENT '内容类型',
    source_id BIGINT COMMENT '来源ID',
    target_id BIGINT COMMENT '目标ID',
    correlation_id VARCHAR(100) COMMENT '关联ID',
    metadata JSON COMMENT '元数据',
    timestamp TIMESTAMP DEFAULT CURRENT_TIMESTAMP COMMENT '时间戳',
    
    FOREIGN KEY (agent_id) REFERENCES agent_instances(id) ON DELETE CASCADE,
    INDEX idx_agent (agent_id),
    INDEX idx_direction (direction),
    INDEX idx_timestamp (timestamp),
    INDEX idx_correlation (correlation_id),
    FULLTEXT idx_content (content)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci COMMENT='消息表';
```

### 8. 系统配置

#### system_settings - 系统设置表
```sql
CREATE TABLE system_settings (
    id BIGINT PRIMARY KEY AUTO_INCREMENT,
    category VARCHAR(50) NOT NULL COMMENT '设置分类',
    key_name VARCHAR(100) NOT NULL COMMENT '设置键',
```

## 关系图

```
users (1) -----> (N) agent_templates

users (1) -----> (N) workflows
users (1) -----> (N) capabilities
users (1) -----> (N) components

agent_templates (1) -----> (N) agent_configs

```

## 索引策略

### 主要索引
1. **主键索引**: 所有表的id字段
2. **外键索引**: 所有外键字段
3. **唯一索引**: username, email等唯一字段
4. **复合索引**: 常用查询组合字段
5. **全文索引**: 搜索相关字段

### 性能优化
1. **分区策略**: 日志表按时间分区
2. **归档策略**: 历史数据定期归档
3. **缓存策略**: 热点数据Redis缓存
4. **读写分离**: 主从复制分离读写

## 数据安全

### 备份策略
1. **全量备份**: 每日凌晨全量备份
2. **增量备份**: 每小时增量备份
3. **binlog备份**: 实时binlog备份

### 权限控制
1. **用户权限**: 基于角色的访问控制
2. **数据权限**: 行级权限控制
3. **API权限**: 接口级权限验证

## 监控指标

### 数据库监控
1. **连接数**: 当前连接数和最大连接数
2. **查询性能**: 慢查询监控和优化
3. **存储空间**: 表空间使用情况
4. **复制延迟**: 主从复制延迟监控

### 业务监控
1. **用户活跃度**: 日活、月活统计
2. **Agent使用情况**: 创建、运行统计
3. **工作流执行**: 成功率、失败率统计
4. **系统性能**: 响应时间、吞吐量统计
