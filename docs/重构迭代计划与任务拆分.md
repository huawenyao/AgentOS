## 二、迭代计划总览

### 6个Sprint，每Sprint 2周

```
Sprint 0 (Week 1-2)    项目脚手架 + 清理
Sprint 1 (Week 3-4)    Connect模块 + 基础数据模型
Sprint 2 (Week 5-6)    Agent设计器 + Playground
Sprint 3 (Week 7-8)    工作流引擎 + 工作流编排器
Sprint 4 (Week 9-10)   Run运行 + 人工审批
Sprint 5 (Week 11-12)  Measure度量 + 端到端联调
```

### 里程碑

| 里程碑 | 时间点 | 可演示的成果 |
|--------|--------|------------|
| **M0: 骨架可跑** | Week 2末 | 新项目结构建立，旧代码迁移完毕，`pip install -e .` 可用 |
| **M1: 单Agent可用** | Week 6末 | 接入一个API → 设计Agent → Playground对话 → 调用真实工具 |
| **M2: 工作流可跑** | Week 8末 | 设计2-3个Agent → 编排工作流 → 端到端执行一次 |
| **M3: 生产可用** | Week 12末 | 完整四步闭环，可交付给内部试用/Demo客户 |
