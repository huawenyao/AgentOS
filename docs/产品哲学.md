# 产品哲学

## 一句话

**对话是主体，可视化是AI思维的外化。**

## 三个不是

| 它不是 | 因为 |
|--------|------|
| 工作流编辑器 | 用户不画流程图。AI自己规划 |
| Chatbot平台 | 不是给终端客户用的Bot。是给业务人员自己用的工作台 |
| BI仪表盘 | 图形不是固定报表。是AI根据当前问题动态生成的思维工具 |

## 可视化的角色

| 维度 | 说明 |
|------|------|
| **谁画图** | AI根据场景和数据动态生成 |
| **图的作用** | 创意引导、思维辅助——帮用户看到结构、趋势、关联、风险 |
| **交互方式** | 自然语言对话。用户可以对着图追问 |
| **图的形态** | 根据思维需要变化：思维导图、决策树、数据图表、关系网络... |
| **图何时出现** | AI判断需要视觉辅助思考时自动呈现 |

## 思维类型→图形类型映射

```
看全貌 → 思维导图/树形图
看趋势 → 时间线/折线图
做对比 → 表格/柱状图
找关联 → 网络图/因果图
做选择 → 决策树
看占比 → 饼图
看数字 → KPI卡片
理步骤 → 流程图
```

图形的选择不基于"数据类型"，而基于**用户需要什么样的思维辅助**。
